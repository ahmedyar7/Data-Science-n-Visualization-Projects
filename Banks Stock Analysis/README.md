# 📈Stock Price Visualization of Major Banks (2006-2016)📉

This project focuses on data analysis and visualization of stock prices for major banks from 2006 to 2016. The banks included in this analysis are Citigroup (C), JPMorgan Chase (JPM), Morgan Stanley (MS), Goldman Sachs (GS), Wells Fargo (WFC), and Bank of America (BAC).

## 📊 Project Description

The goal of this project is to analyze and visualize the stock price trends of the aforementioned banks over a decade. The analysis includes various types of visualizations to provide insights into the stock price movements, trends, and patterns during this period.

## 🛠️ Libraries Used

- **Pandas:** For data manipulation and analysis.
- **Plotly:** For interactive visualizations.
- **Seaborn:** For statistical data visualization.
- **Matplotlib:** For 2D plotting.

## 📈 Data Source

The stock price data used in this project is sourced from **stooq** Finance.

## Visualizations

The project includes the following types of visualizations:

- 📅 Line plots of stock prices over time
- 📊 Rolling mean and rolling standard deviation plots
- 📈 Candlestick charts for detailed stock price analysis
- 🔗 Pair plots to show relationships between different stocks
- 🔥 Correlation heatmaps to identify correlations between the stock prices
