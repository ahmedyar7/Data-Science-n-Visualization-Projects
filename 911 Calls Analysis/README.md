# 📞 911 Calls Data Analysis

This project analyzes and visualizes the 911 calls dataset from Kaggle to identify different reasons for the calls from various townships. The analysis is performed using **Python** with the help of **Pandas** for data manipulation and analysis, and **Matplotlib** and **Seaborn** for data visualization.

## 📝 Introduction

Emergency 911 calls data provides insights into the reasons for calls, the time of day, and the location of the incidents. By analyzing this data, we can better understand the patterns and trends in emergency situations.

## 📊 Dataset

The dataset used for this project is available on Kaggle: [911 Calls Dataset](https://www.kaggle.com/mchirico/montcoalert)

## 🛠️ Installation

To run this project, you need to have Python installed along with the following libraries:

- **Pandas**
- **Matplotlib**
- **Seaborn**
- **Plotly**

You can install these dependencies using pip:

```bash
pip install pandas matplotlib seaborn
```

## 📈 Data Analysis

In this project, we perform the following data analysis tasks:

- 🔄 Load and clean the data.
- 📅 Extract relevant information such as call time, reason, and location.
- 🏘️ Analyze the number of calls per township.
- 📊 Identify the most common reasons for 911 calls.

## 📉 Visualizations

We use Matplotlib and Seaborn to create visualizations that help in understanding the data better.

**Some of the visualizations include:**

- 📊 Bar plots for the number of calls per township.
- 🥧 Pie charts for the distribution of call reasons.
- 🌡️ Heatmaps for the call frequency over time.

## 🔍 Results

**The analysis reveals interesting patterns in 911 call data. For example:**

- 🏘️ The township with the highest number of calls.
- 🚑 The most common reasons for 911 calls.
- 🕒 Temporal patterns in the frequency of calls.
